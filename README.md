# 🚀 DeepSeek Harness 一键启动器（Windows）

双击一下，就能帮你把 DeepSeek Harness启动起来。



---

## 这个工具是干什么的？


这个仓库里有 **2 个脚本**，可以帮你跳过执行命令行这一步骤，**双击就行**。

- ✅ 适合不熟悉/不习惯命令行，习惯桌面端or不想每次启动harness都先用命令行
- ✅ 不需要任何命令
- ✅ 全程点点鼠标

---

## 📁 两个脚本，分别能干嘛？

| 脚本文件 |什么时候用它 |
| **`OpenDeepSeek.vbs`** | 点击=替代“写命令行” ，之后直接启动ds harness web就行，适合不想每次使用都先写命令行但使用web端|
| **`Start DeepSeek Harness.vbs`** | 一键启动dsharness，双击直接启动，适合桌面端使用习惯 |


```
OpenDeepSeek.vbs        =  点击省略写命令行，网页端自己开
Start DeepSeek Harness  =  一键自动开网页，省却写命令行，更符合桌面端习惯（推荐新手选这个）
```

---

## 🎯 我需要装什么？（前提条件）

只用确认一件事：**电脑上已经装好 Node.js 。（可以让ds直接帮你装）

> 怎么确认装没装？打开"开始菜单"，输入 `cmd` 回车，在弹出的黑窗口里输入：
> ```
> dsh web
> ```
> - 如果没报"找不到命令"，说明可以用了 ✅
> - 如果报"不是内部或外部命令"，说明还缺 Node.js，装好再来。

---

## ▶️ 怎么用？（超简单三步）

1. **把两个脚本文件下载到你的电脑**（随便放哪个文件夹都行，比如 `D:\dsh`）。
2. **双击脚本**，搞定。

---

## 📌 关于脚本里的 `WorkPath = "D:\dsh"`

两个脚本顶部都有一行 `WorkPath = "D:\dsh"`。

**它是什么意思？**
它不是"脚本的安装位置"，而是给脚本指定一个**"工作 / 数据存放文件夹"**。脚本运行时，会把这个文件夹设置为它的工作目录，之后 DeepSeek Harness 产生的临时数据、配置等，就会**统一存在这个文件夹里**。

**需要改吗？一般都不用。**
- 正常情况下**不改也能正常启动**（服务是靠系统环境变量找到的，跟这个路径无关）。
- 除非你希望数据存放在**别的文件夹**，才需要把 `"D:\dsh"` 改成你想要的那个文件夹路径。

## 🆚 两个脚本的启动体验对比

| | `OpenDeepSeek.vbs` | `Start DeepSeek Harness.vbs` |
| --- | --- | --- |
| 后台启动服务 | ✅ | ✅ |
| 自动等待服务就绪 | ❌（不等，后台转） | ✅（每 0.2 秒检查一次） |
| 自动弹出浏览器 | ❌ 不弹，自己开 | ✅ 自动弹 |
| 适合人群 | 熟悉一点的用户 | **完全新手（推荐）** |
| 会不会白屏等待 | 由自己刷新 | 不会，就绪才弹 |

> `Start DeepSeek Harness.vbs` 用的是"轮询等待"：每 0.2 秒看一次服务准备好没，好了立刻弹浏览器，**快且不白屏**。

## ❓ 常见问题（FAQ）

**Q: 双击后浏览器没弹出来？**
A: 先确认服务真的启动了——手动打开浏览器，输入 `http://127.0.0.1:3080` 看看能不能访问。能访问说明脚本没问题，只是没弹出来。

**Q: 双击后闪了一下就没了？**
A: 这**是正常现象**。脚本本来就是在后台干活，窗口一闪而过就是在后台启动服务的信号。

**Q: 我根本不知道 Node.js 是什么，能装吗？**
A: 能，搜"Node.js 中文官网"下载安装即可（安装时一路点"下一步"就行）。装完再回来看本文件。

## 🛠 想自己微调？（进阶）

以下都写在脚本顶部，用记事本打开就能改：

- `WorkPath`：工作文件夹路径（见上文）。
- `ENABLE_AUTO_START = False`：改成 `True` 可开机自动启动（建议先别改，等熟悉了再说）。
